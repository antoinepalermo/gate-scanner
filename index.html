🛠 How to fix the camera (tap here)
Fix the live camera:
  1. Tap the 🔒 icon beside the web address at the top.
  2. Tap Permissions → Camera → Allow.
    If Camera is not listed, tap Reset permissions.
  3. Reload this page. When asked, choose
    "Allow while visiting the site" (NOT "Only this time").
  4. Still blocked? Check the phone itself: long-press the Chrome icon → App info → Permissions → Camera → Allow. Then reopen this page.

While waiting, keep using 📷 Scan by Photo — scans are logged exactly the same way.
